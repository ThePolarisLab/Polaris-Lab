## Approved Parallel Workstreams

Polaris follows this connector strategy:

> Connect several priority systems in parallel, validate each independently, preserve source evidence, and integrate them only through governed normalization, canonical enterprise models, and executive read models.

Each connector must remain independently governed with its own adapter, credentials and permissions, checkpoints, sync history, health state, failure handling, tests, persistence ownership, and production acceptance evidence. Connectors must not write directly into another connector's provider-owned tables.

## v1.0 Scope Decision

Production readiness must be judged against explicitly approved in-scope exit criteria.

Current internal v1.0 baseline:

- security and tenant isolation complete;
- persistent PostgreSQL deployment complete;
- production authentication bootstrap complete;
- QuickBooks read-only production connector verification complete for Mor Logistics;
- QuickBooks financial reconciliation is tracked separately as Track 4A;
- ADR-028 / PES-001 is the approved standard for Balance Sheet executive KPI totals;
- Outlook and Motive are approved as parallel, separately governed activation tracks rather than automatically deferred to v1.1;
- external identity remains a separate release decision;
- repository visibility remains an owner-controlled action and should be set to private unless stakeholders explicitly approve public visibility.

A broader external v1.0 should additionally require:

- external identity provider decision and implementation;
- stakeholder decision on whether Outlook and Motive activation must be included in the v1.0 label;
- final observability, release controls, and repo visibility review.
