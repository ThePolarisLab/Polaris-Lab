# Polaris v1.0 Punch List

Status date: 2026-07-31

Current v1.0 completion estimate: 86-89%. Security, tenant isolation, database lifecycle, persistent deployment hardening, production authentication bootstrap, and the QuickBooks production adapter implementation are merged. Remaining production readiness is concentrated in QuickBooks live operator verification, the QBO sync-history hotfix deployment, Motive, external identity, final operational controls, and an explicit v1.0 scope decision.

Status: Complete and merged.

## Phase 3B: Production Authentication Bootstrap

Status: Core implementation merged and deployed; production bootstrap/login verified after hotfixes.

Scope completed:

## v1.0 Scope Decision

Recommended internal v1.0 scope:

- security and tenant isolation complete;
- persistent PostgreSQL deployment complete;
- production authentication bootstrap complete;
- QuickBooks read-only live verification complete for Mor Logistics;
- Motive and Outlook explicitly deferred to v1.1 unless human stakeholders require them for v1.0.

A broader external v1.0 should additionally require:

- external identity provider decision and implementation;
- Motive production adapter or a documented deferral accepted by stakeholders;
- final observability, release controls, and repo visibility review.

## Later Phases

The following phases are intentionally out of scope for Phase 3B/3B.1:

1. Motive production adapter / Issue #62.
2. Outlook production adapter.
3. API-001 response/versioning migration.
4. QuickBooks accounting writes.
5. Broad CI/CD hardening unrelated to auth/QBO verification.
6. External production identity provider.

Do not mark Polaris v1.0 production-ready until every in-scope phase has passing automated evidence, production operator evidence where required, and human approval.
