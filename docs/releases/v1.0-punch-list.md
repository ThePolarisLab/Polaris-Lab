# Polaris v1.0 Punch List

Status date: 2026-07-29

## Phase 1: Security Gate

Status: In progress, not complete.

Scope:

- route-security inventory;
- backend authentication and permission enforcement;
- organization-context validation;
- production local-auth secret hardening;
- QuickBooks OAuth state binding;
- frontend session handling;
- backend and frontend security tests.

Completion criteria:

- all Python tests pass;
- all TypeScript tests pass;
- frontend tests pass;
- frontend production build passes;
- route-security matrix matches implementation;
- repository search confirms no unintentionally public FastAPI routes;
- repository search confirms `polaris-dev-only` cannot be used silently in production;
- draft PR is reviewed and approved.

Current status:

- Route-security matrix added in `docs/security/route-security-matrix.md`.
- Auth flow and environment requirements updated in `docs/security/production-auth.md`.
- Implementation and tests are present on `phase1/security-gate`.
- Gate remains open until verification passes in a working test environment.

## Later Phases

The following phases are intentionally out of scope for Phase 1:

1. Database migrations and persistence lifecycle.
2. Motive production adapter.
3. Outlook production adapter.
4. API-001 response/versioning migration.
5. Deployment manifests and production runbooks.
6. CI/CD hardening beyond the checks required to validate this gate.

Do not mark Polaris v1.0 production-ready until every phase has passing automated evidence and human approval.
