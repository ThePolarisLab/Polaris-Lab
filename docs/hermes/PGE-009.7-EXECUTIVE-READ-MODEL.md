# PGE-009.7 — Executive Read Model

## Purpose

The Executive Read Model translates connector evidence into provider-neutral business entities that can be queried by Athena and executive-facing applications.

## Architectural rule

Connectors collect evidence. Projections interpret evidence. The Executive Read Model exposes business state. Athena reasons over that state.

Vendor-specific API objects must not enter the executive domain.

## Initial domain

- Executive Customer
- Executive Load
- Executive Vehicle
- Executive Driver
- Executive Financial Snapshot
- Executive Task
- Executive Alert
- Executive KPI
- Business Event

Every entity has a stable Polaris identity, organization scope, optimistic version, external references, evidence references, timestamps, and metadata.

## Repository

`ExecutiveRepository` provides provider-neutral storage and querying. The first implementation is in-memory and enforces:

- entity validation
- organization isolation
- monotonically increasing versions
- immutable stored values
- idempotent business events

A durable adapter may replace the in-memory implementation without changing consumers.

## Query and briefing services

`ExecutiveQueryService` assembles business-focused dashboard views and prioritized alerts.

`ExecutiveBriefingService` creates a deterministic structured briefing containing critical alerts, open tasks, active loads, fleet and driver availability, and the latest financial snapshot.

## Evidence and explainability

Evidence references preserve connector identity, source resource identity, observation time, confidence, and optional source URL. Future projections must attach the source evidence supporting every material executive fact.

## Explicit exclusions

This increment does not include:

- connector-specific projection implementations
- durable database persistence
- entity-resolution or duplicate-customer matching
- knowledge graph storage
- Athena reasoning
- autonomous actions
- user interface

## Next increment

Add projection contracts and source-specific projections for Outlook, Motive, and QuickBooks evidence, followed by durable persistence and identity resolution.
