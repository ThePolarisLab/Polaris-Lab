# PGE-009.10.2 — Reference Connector Certification

## Objective

Certify the Outlook, Motive, and QuickBooks reference connectors against the Hermes provider-neutral connector contracts.

## Outcome

The reference adapters are covered by automated certification tests for descriptor conformance, scope isolation, governed evidence envelopes, provenance, deterministic idempotency keys, credential-reference non-disclosure, checkpoint schema declarations, health reporting, and lifecycle transitions.

## Boundary

This increment certifies controlled reference-adapter behaviour. It does not certify live Microsoft, Motive, or Intuit availability; production credentials; vendor data accuracy; rate-limit behaviour; credential-vault integration; or production service levels.

## Evidence

- `tests/certification/referenceConnectorCertification.test.ts`
- `tests/certification/certificationManifest.ts`
- `docs/hermes/HERMES_REFERENCE_CONNECTOR_CERTIFICATION.md`
- `.github/workflows/hermes-certification.yml`

## Decision

HCF-001 is recorded as passed when CI succeeds and the pull request is approved and merged. Remaining integration, resilience, security, traceability, Athena, and release criteria stay planned for later PGE-009.10 increments.
