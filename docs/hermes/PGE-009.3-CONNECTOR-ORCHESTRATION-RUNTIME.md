# PGE-009.3 — Connector Orchestration Runtime

## Status

Implemented in PR #53.

## Scope

This milestone introduces the provider-neutral execution layer for Hermes connectors:

- `ConnectorRegistry` for registration and capability discovery
- `ConnectorRuntime` for lifecycle-aware synchronization
- bounded retry with disconnect/reconnect recovery
- checkpoint persistence abstraction with an in-memory implementation
- runtime events for synchronization start, success, and failure
- unit coverage for registration, checkpoint resume, retry, and events

## Runtime flow

1. Resolve a connector from the registry.
2. Connect it when it is not already connected or degraded.
3. Load the prior checkpoint for incremental synchronization.
4. Execute synchronization.
5. Persist the returned checkpoint.
6. Publish runtime events.
7. On failure, disconnect, reconnect, and retry within the configured bound.

## Boundaries

This milestone intentionally excludes vendor-specific connectors, durable storage, distributed scheduling, webhook ingestion, and Mission Control UI work. Those remain follow-on milestones.
