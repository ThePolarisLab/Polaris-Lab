# PGE-009.5 — Motive Connector

## Purpose

The Motive connector brings fleet-operational evidence into Hermes using the connector contracts and orchestration runtime established in PGE-009.2 and PGE-009.3.

## Included resources

- vehicles;
- drivers;
- vehicle locations;
- vehicle utilization;
- driver utilization;
- IFTA summaries.

The resource list is configurable so later Motive endpoints can be added without changing connector lifecycle behavior.

## Design

`MotiveConnector` extends `AbstractConnector` and depends on the narrow `MotiveApiClient` port. Authentication, retries, reconnects, and checkpoint persistence remain runtime responsibilities.

Each Motive record is emitted as a `motive-record-v1` evidence envelope containing:

- resource type;
- source record identifier;
- source update timestamp;
- original typed record payload;
- stable correlation and idempotency metadata.

## Incremental synchronization

The checkpoint stores the most recent record update timestamp and any unfinished per-resource pagination cursors. Incremental runs pass the timestamp to every configured resource and resume unfinished pages where needed.
