# PGE-009.4 — Microsoft Outlook Connector

## Purpose

The Outlook connector is the first production-oriented Hermes source adapter. It converts Microsoft Graph mail records into evidence envelopes while delegating retries, lifecycle management, and checkpoint persistence to `ConnectorRuntime`.

## Design

`OutlookConnector` extends `AbstractConnector` and depends on the narrow `GraphMailClient` port. The port keeps Microsoft Graph SDK and OAuth implementation details outside the Hermes contract layer and makes the connector deterministic to test.

On connection the connector:

1. authenticates using a credential reference supplied by the runtime context or descriptor;
2. discovers mailbox folders;
3. transitions to the standard connected state.

During synchronization it:

1. uses the stored Graph delta cursor for incremental requests;
2. follows Graph pagination links;
3. emits one `EvidenceEnvelope` per message;
4. includes message body fields and attachment metadata;
5. returns the latest delta link as a Hermes checkpoint.

## Evidence schema

Each envelope uses schema version `outlook-message-v1` and an idempotency key composed from connector ID and Graph message ID. Attachment bytes are intentionally excluded from this milestone; only metadata is captured.

## Runtime integration

```ts
const connector = new OutlookConnector(graphClient, options);
const registry = new ConnectorRegistry();
registry.register(connector);
const runtime = new ConnectorRuntime(registry, checkpointStore);

await runtime.synchronize(
  connector.descriptor.identity.id,
  context,
  SynchronizationMode.Incremental,
  correlationId,
);
```

## Included

- authentication boundary;
- folder discovery;
- full and incremental message synchronization;
- bodies, recipient fields, links, and attachment metadata;
- pagination and delta checkpoints;
- health reporting;
- unit tests using a fake Graph client.

## Deferred

- concrete Microsoft Graph SDK adapter;
- interactive OAuth user interface;
- attachment byte download and storage;
- sending, replies, drafts, archive/move, and categories;
- calendar, contacts, tasks, and webhook subscriptions.
